## 📚 Workshop Notes

### 01. Understanding Git & GitHub

Git merupakan sistem *version control* yang digunakan untuk mencatat dan mengelola perubahan pada file dalam sebuah project. Dengan Git, setiap perubahan dapat disimpan sebagai riwayat sehingga memudahkan pengguna dalam memantau perkembangan project maupun kembali ke versi sebelumnya.

Sementara itu, GitHub merupakan platform berbasis web yang memungkinkan repository Git disimpan secara online. GitHub juga dapat digunakan untuk berbagi source code dan berkolaborasi dengan pengembang lainnya.

<details>
<summary><b>💡 Git vs GitHub</b></summary>

| Git | GitHub |
|---|---|
| Version Control System | Platform hosting repository |
| Mengelola perubahan file | Menyimpan repository online |
| Berjalan secara lokal | Dapat diakses melalui internet |
| Mencatat riwayat project | Mendukung kolaborasi |

</details>

### 02. Basic Git Commands

Beberapa perintah dasar Git yang dipelajari selama workshop:

| Command | Fungsi |
|---|---|
| `git init` | Membuat repository Git lokal |
| `git status` | Memeriksa status perubahan file |
| `git add .` | Menyiapkan perubahan file |
| `git commit -m "message"` | Menyimpan catatan perubahan |
| `git remote add origin URL` | Menghubungkan repository ke GitHub |
| `git push` | Mengirim perubahan ke GitHub |
| `git pull` | Mengambil perubahan dari GitHub |
| `git log` | Melihat riwayat commit |

### 03. Working with GitHub & VS Code

Penggunaan Git tidak selalu harus melalui terminal. Visual Studio Code menyediakan fitur **Source Control** yang membantu pengguna mengelola perubahan project melalui antarmuka grafis.

Alur penggunaan yang dipelajari dimulai dengan membuka folder project di VS Code, menginisialisasi Git, kemudian melakukan perubahan pada file. Setelah itu, perubahan dapat dimasukkan ke staging area, disimpan melalui commit, dan dikirim ke repository GitHub menggunakan push.

<details>
<summary><b>⚡ Basic Workflow</b></summary>

```bash
# Initialize repository
git init

# Add files
git add .

# Save changes
git commit -m "Initial commit"

# Connect to GitHub
git remote add origin https://github.com/username/repository.git

# Set main branch
git branch -M main

# Upload project
git push -u origin main
```

</details>
